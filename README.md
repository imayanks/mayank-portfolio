## ⚙️ Running Locally

Clone the repository:

```bash
git clone https://github.com/imayanks/mayank-portfolio.git
```

Move into the project:

```bash
cd mayank-portfolio
```

Open `index.html` in your browser, or serve the project using a local web server.
